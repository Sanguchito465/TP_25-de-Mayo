## Estructura
- `index.html` → página principal solicitada por la consigna.
- `semana.html` → Sección 1: Semana de Mayo.
- `lugares.html` → Sección 2: Lugares y símbolos.
- `legado.html` → Sección 3: Legado y actualidad.
- `css/style.css` → hoja de estilos externa comentada.
- `img/` → ilustraciones originales del proyecto.
- `video/video_25_mayo.mp4` → video educativo animado original.

## Bootstrap
Se usa Bootstrap 5.3.3 mediante CDN. Para que los componentes interactivos funcionen correctamente al abrir el sitio, se necesita conexión a Internet.

Componentes utilizados: Accordion, Buttons, Table, Alert, Cards, Collapse y Carousel.
